# Target Roles — With Descriptions

1. **AI Agent Engineer** — builds, deploys, and maintains autonomous AI agents (using LangGraph, CrewAI, AutoGen, etc.)
2. **Agentic Workflow Architect** — designs multi-agent orchestration pipelines (planning, tool use, memory, handoffs)
3. **Agent Observability Engineer** — monitors agent behavior, catches loops, hallucinations, tool misuse
4. **LLMOps Engineer** — manages LLM lifecycle: prompt testing, versioning, eval benchmarks, latency/cost optimization
5. **Prompt Engineer** — designs and refines prompts as a dedicated role, often senior-level
6. **RAG Engineer** — builds retrieval-augmented generation pipelines: chunking strategies, embedding tuning
7. **Model Router / Gateway Engineer** — handles API routing, fallback chains, caching, cost allocation across multiple models
8. **AI Alignment Specialist** — works on RLHF, DPO, constitutional AI, safety guardrails
9. **Eval Engineer** — builds and maintains evaluation benchmarks for agentic systems (tool-calling accuracy, multi-step reasoning, plan adherence)
10. **Synthetic Data Engineer** — generates, validates, and curates synthetic datasets for fine-tuning agents
11. **Knowledge Base Architect** — structures vector stores, knowledge graphs, and tool APIs for agent consumption
12. **Embedding Pipeline Engineer** — builds efficient chunking/embedding/retrieval systems at scale
13. **AI Integration Engineer** — connects LLMs with existing APIs, SaaS tools, databases, and automations
14. **Agent UX / Interaction Designer** — designs chat interfaces, multi-turn workflows, error recovery for agentic products
15. **AI Product Engineer (Agentic)** — builds product features that heavily leverage agents; often needs full-stack + LLM knowledge
16. **AI Agent for Enterprise Automation** — builds custom agents for internal tools (Slack bots, CRM agents, support automation)
17. **Text-to-SQL / Code Agent Developer** — specializes in agents that generate and execute SQL/code
18. **Autonomous Systems Engineer** — builds complex long-running agents (research agents, code generation pipelines, multi-agent swarms)
19. **Site Reliability Engineer / Platform Reliability Engineer** — keeps production systems running: incident response, service re-architecture, reliability engineering; increasingly overlapping with agentic-AI skills per market signal
