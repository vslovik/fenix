Product team hiring a full-stack engineer to build customer-facing features end to end. You will
work in TypeScript across the whole stack: React on the front end, Node services behind it, and the
API layer between them. Design comes from a product designer in Figma; you turn it into working
interface.

Day to day this is feature delivery — new screens, forms, state management, responsive layout,
accessibility, and the endpoints that back them. You will work closely with product and design in a
two-week cycle, ship behind feature flags, and iterate based on usage data.

We use Next.js, a component library, and a managed database. Testing is Playwright end to end plus
unit tests on the service layer. Deployment is continuous.

We are looking for someone who cares about the details of an interface — how it feels when it is
slow, what happens on a bad connection, whether the empty state makes sense — and who is happy
spending most of their time in the browser.
